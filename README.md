# Python Lists and Tuples

A collection of Python exercises exploring sequences, indexing, mutability, iteration, and structured data.

## What This Repository Covers

- Creating and modifying lists
- Working with immutable tuples
- Indexing and slicing
- Sorting and combining sequences
- Nested lists and tuples
- Unpacking and enumeration
- Iterating through structured data
- Small practice exercises involving menus and data cleaning

## Getting Started

**Requirement:** Python 3.

Clone the repository and run an exercise directly:

```bash
python list_intro.py
python tuples_intro.py
python nested_data.py
```

Some files have spaces in their names. Use quotation marks around those paths when running them.

## Suggested Learning Path

1. Begin with `list_intro.py` and `tuples_intro.py`.
2. Explore mutability with `mutable.py` and `immutable.py`.
3. Practise nested data and unpacking.
4. Review the sorting and enumeration examples.
5. Work through the small projects and data-cleaning exercises.

## Scope

This repository documents Python practice exercises, not a reusable software package. Each script can be reviewed independently.
